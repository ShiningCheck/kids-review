# 学习复盘录音精剪 · 详细口径

本文档是**学习复盘录音**（本技能 `kids-review-editing`）的详细口径；
**口播视频**精剪（含封面、片尾、录屏变体）走姊妹技能 **`oral-broadcast-editing`**。

> ⚠️ 日常跑法优先走 `SKILL.md` 的「纯音频分支」（`transcribe.py` → 手写 `mk_drop.py`
> 定 KEEP → `est_duration.py` → `cut_audio.py --plain --pitch-mode beep` → 复检 → `md2docx.py`）。
> 本文档描述的 `review_*` 管线是**可选路径**（多出 srt 和可勾选恢复的复核页 HTML），
> 用户没点名要复核页时不要走它；下面「语义筛选」「易误判」「分组」三节的口径两条路径通用。
> 阶段二成片视频（封面 + ASS 字幕 + mp4）见 `SKILL.md` 的「阶段二：封面与成片视频」。

## 与其他剪辑任务的差异（先看清再动手）

| | 口播视频（`oral-broadcast-editing`） | 学习复盘音频（本技能） |
|---|---|---|
| 输入 | 一段/多段口播录像 | 一段亲子对话录音（10–20 分钟） |
| 保留 | 讲者主体内容，删语气词/口吃/跑题 | **孩子与大人围绕学习内容的交互** + 孩子的学习内容描述 |
| 产出 | 成片 mp4（片头+字幕+片尾）+ 封面 | **精剪 mp3 + 逐字稿（md/docx）**，阶段二可继续出成片 mp4 |
| 封面 | 要（两套定稿风格） | 阶段一不要；阶段二按当天水彩画生成 |
| 片尾 | 要（点击关注不迷路 + reThink） | 不要 |
| 字幕 | 烧进画面（ASS） | 阶段一只出 srt（成片台词）；阶段二烧 ASS |
| 复核页 | 要 | 要（已删内容分组勾选恢复） |

**判定话术**：用户说「复盘」「今天孩子在学校…」「保留和孩子的互动」→ 本技能；
说「口播」「剪视频」「加封面」→ `oral-broadcast-editing`。拿不准就问一句，别猜。

## 源文件：音频和视频常在同一文件夹

常见录屏/录音下载目录（例如网易 GameViewer 的下载目录）里
**.mp4 和 .mp3 混在一起**，还有同名的录屏。做法：

1. 列出目录里所有 `.mp3 / .m4a / .wav / .mp4`，看时长和修改时间
2. **复盘录音通常是纯音频、时长 10–20 分钟、傍晚/睡前录的**；
   口播录像是 mp4、几分钟到十几分钟
3. 不确定的话先用 `ffprobe` 看时长和音轨数（视频文件有视频流，音频文件没有）
4. 确认后**记下确切文件名**再往下走，别用通配符一把梭

## 流程（5 步）

```bash
# 先运行 scripts/setup.py，使用它输出的 PY 和 S：
PY="<setup.py 输出的 PY>"
S="<skill 目录>/scripts"
cd 工作目录

# 1) 转写（--tag 给输出起名，别让默认 v1 混进别的批次）
$PY $S/transcribe.py day2.mp3 -o . --tag day2        # → day2_16k.mp3 + day2_asr.json

# 2) 人工读 day2_asr.json 的 utterances，按下面口径定保留清单 → day2_edl.json
#    （这一步没有脚本，语义判断必须人来做）

# 3) 精剪 + 成片台词
$PY $S/review_cut.py --asr day2_asr.json --src day2.mp3 --edl day2_edl.json \
     -o day2_final.mp3 --srt day2_final.srt --keep day2_keep.json

# 4) 逐字稿文档（md / txt / html / docx）
$PY $S/review_doc.py --keep day2_keep.json --asr day2_asr.json \
     --sections sections.json --title "9月10日 学习复盘" --meta "2026年9月10日（周四）" \
     -o day2_transcript

# 5) 复核页（已删内容分组勾选恢复）
$PY $S/review_page.py --keep day2_keep.json --asr day2_asr.json --audio day2_final.mp3 \
     --srt day2_final.srt --groups groups.json --sections sections.json -o review_day2.html
```

## 第 2 步：语义筛选口径（这条是复盘录音的核心）

**保留**：
- 孩子描述当天学了什么（课程内容、老师怎么讲、自己做了什么）
- 师生互动、课堂问答
- **围绕学习内容的亲子问答**（「手能干什么呀爸爸」「你猜有几个格子」——这种要留）

**删除**：
- 生活流水账：吃饭/打饭、纸巾、吃梨、放学等车、骑车
- 课堂流程：起立问好、喝水上厕所、下课铃、大课间
- 拟声与纯语气碎片（「嗯」「嘿嘿嘿」「铛铛铛」单独成句时）
- 与学习无关的玩闹

**语气词规则在复盘录音里几乎无效**：口语对话里全是语气词，用规则删会把内容一起删掉。
必须**人工读完全文，按 utterance 索引挑**，规则只能处理「整句删除」和「句首/句尾碎片裁切」。

### 易误判（我在 9/9、9/10 都踩过）

| 看着像可删 | 实际要留 |
|---|---|
| 「来，我们看一下这个」 | **家长的引导句**——它引出后面孩子的学习内容 |
| 「把书翻开第 12 页」 | **课前准备句**——带课程信息（哪一课、哪一页） |
| 「今天先说到这，明天我们讲…」 | **过渡句**里常有对当天内容的总结 |
| 孩子重复讲同一件事 | 第一次是复述、**第二次常是理解性的补充**，别一律当重复删 |

判定口诀：**看这一句是否围绕学习内容**，不是在讲「生活」还是在讲「学习」。

### 分组（复核页用）

删掉的句子也要分组，用户要能一眼找回：

- `生活流水账` / `课堂仪式与课间` / `语气词与拟声` / `疑似可恢复` / `未归类`
- **`疑似可恢复` 这组必须逐句看一眼**：与学习沾边但当前被删掉的，往往是误删

复核页底部按钮输出「恢复索引：3,7,12」，加回 edl 的 `keep` 重跑第 3 步即可。

## 剪辑单 edl.json 格式

```json
{
  "keep": [0, 1, 3, 4],
  "trim_head": {"3": "第一节是美术课"},
  "tail_trim": {"8": ["花纹", "花纹"]},
  "replace":  {"7": [["老师说需", "老师就说要把"]]},
  "pad_head": 120, "pad_tail": 250, "merge_gap": 1200
}
```

- `trim_head` / `tail_trim`：**词级定位**，用 `words` 时间戳找标记词的起止，
  别用字符比例估算（ASR 文本和词表不一定对齐）
- `tail_trim` 是 `[音频标记词, 字幕标记词]` 二元组：音频按前者切、字幕按后者切
- `replace` **只改字幕文本不动音频**，用于修 ASR 错字、提升可读性
- `pad_head/pad_tail`：每段首尾留白（默认 120/250 ms），不留会吞掉首尾字
- `merge_gap`：相邻段间隔小于此值就合并（默认 1200ms）——
  注意这与口播视频的「0.2–1s 停顿要保留」规则不同，复盘成片是拼接必须紧

## 逐字稿的规矩

- **不带时间码、不带句号编号**（用户明确要求过「把字幕文字去掉时间变成完整文档」）
- 按课程/小节分段（美术课 / 科学课 / 体育课 …），`sections.json` 必须覆盖 keep 里每一句，
  脚本会断言检查有没有漏
- 断句规则：以「是」结尾说明话没说完，**不能断**
- 成稿替换表（`--fix`）只影响文档，不动音频
- docx：正文宋体 12pt，**必须设 `w:eastAsia`**，否则中文不生效；小节标题用 `#d91ad9`

## 增量（每天都要做）

用户是**每日**复盘，所以按日期组织产物，别互相覆盖：

```
2026-09-10/  day2.mp3  day2_asr.json  day2_edl.json  day2_keep.json
             day2_final.mp3  day2_final.srt
             day2_transcript.md / .docx        逐字稿
             review_day2.html                  复核页
```

`transcribe.py --tag` 就是为这个加的（默认 v1/v2 会在第二天被覆盖）。

## 已知坑

1. **`transcribe.py` 对 mp3 同样可用**（`ffmpeg -i` 无所谓音视频），但多个输入时
   `--tag` 不生效（仍用 v1/v2），单输入才用 tag
2. **srt 的时间必须重映射**：成片是拼接的，原始时间码直接用会全错，
   `review_cut.py` 里用 `mapping` 做「原片时间 → 成片时间」换算
3. **docx 中文字体**要设 `w:eastAsia`（见上）
4. **合并段会吞掉句间停顿**：`merge_gap` 太小会显得赶，太大成片时长下不来；1200ms 是实测甜点
5. **`duration_ms` 取最后一个词的 end**，不是文件时长——统计压缩比时以它为准
